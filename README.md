# CutFlow Batch

**Mass Video Cut Tool** — Windows-приложение для быстрой пакетной обрезки начала и конца видео. Оригинальные файлы не изменяются. Сначала используется быстрое копирование потоков без перекодирования, а при несовместимости автоматически включается fallback с H.264/AAC.

## Возможности

- пакетная обработка MP4, MKV, MOV, AVI, WebM и M4V;
- дробные значения обрезки, например `1.5` секунды;
- отдельный рабочий поток: интерфейс остаётся отзывчивым;
- отмена очереди и остановка текущего процесса FFmpeg;
- автоматические имена `name_cut.mp4`, `name_cut_1.mp4` и далее;
- тёмная тема, общий прогресс, статус каждого файла и подробный лог;
- сохранение последней папки вывода и значений обрезки в `cutflow_settings.json` рядом с программой.

## Требования

- Windows 10/11;
- Python 3.11 или новее;
- FFmpeg и FFprobe.

## Установка зависимостей

Откройте PowerShell или командную строку в папке проекта и выполните:

```bat
python -m pip install -r requirements.txt
```

## Установка FFmpeg

Программа ищет `ffmpeg.exe` и `ffprobe.exe` в таком порядке:

1. рядом с `main.py` или `CutFlowBatch.exe`;
2. в системной переменной `PATH`.

Можно скачать Windows-сборку FFmpeg с [официальной страницы загрузки](https://ffmpeg.org/download.html), распаковать её и добавить папку `bin` в `PATH`. Более простой переносимый вариант — скопировать `ffmpeg.exe` и `ffprobe.exe` из папки `bin` рядом с программой.

Проверка установки:

```bat
ffmpeg -version
ffprobe -version
```

## Запуск

```bat
python main.py
```

Добавьте видео, выберите папку вывода, задайте обрезку начала/конца и нажмите **Старт**. По умолчанию используется папка `output` рядом с программой.

## Сборка EXE

Запустите:

```bat
build_exe.bat
```

Скрипт установит зависимости и соберёт один оконный файл:

```text
dist\CutFlowBatch.exe
```

Если `ffmpeg.exe` и `ffprobe.exe` находятся в корне проекта во время сборки, скрипт также скопирует их в `dist`. Иначе положите оба файла рядом с готовым EXE вручную или добавьте FFmpeg в `PATH`.

## Как выполняется обрезка

Для каждого файла FFprobe определяет исходную длительность. Затем вычисляется:

```text
new_duration = original_duration - trim_start - trim_end
```

Если результат меньше или равен нулю, файл пропускается. В остальных случаях FFmpeg сначала запускается с `-c copy`. При ошибке неполный файл удаляется, после чего выполняется повторная обработка с `libx264` и `aac`. Ошибка одного файла не останавливает оставшуюся очередь.
