# Changelog

Формат основан на принципах [Keep a Changelog](https://keepachangelog.com/), при этом версия проекта пока не зафиксирована отдельным номером релиза.

## Initial public import — 2026-08-10

### Added

- графический интерфейс CutFlow Batch на PySide6;
- пакетная очередь видео;
- поддержка MP4, MKV, MOV, AVI, WebM и M4V;
- обрезка начала и конца с дробными значениями времени;
- определение длительности через FFprobe;
- быстрый FFmpeg stream-copy режим;
- fallback-перекодирование в H.264/AAC;
- отмена активной обработки;
- прогресс и статусы по файлам;
- журнал обработки;
- сохранение пользовательских параметров;
- сборка `CutFlowBatch.exe` через PyInstaller;
- `.gitignore` для build/runtime-файлов и локальных FFmpeg-бинарников.
