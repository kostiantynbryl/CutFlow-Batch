# Устранение проблем

## FFmpeg не найден

Сообщение:

```text
FFmpeg не найден
```

или:

```text
FFprobe не найден
```

CutFlow Batch ищет инструменты в следующем порядке:

1. рядом с `main.py` или `CutFlowBatch.exe`;
2. в системной переменной `PATH`.

Проверьте:

```bat
ffmpeg -version
ffprobe -version
```

Для переносимой версии положите рядом с EXE:

```text
CutFlowBatch.exe
ffmpeg.exe
ffprobe.exe
```

## Файл получает статус «Пропущен»

Это происходит, если:

```text
trim_start + trim_end >= duration
```

Например, для видео длительностью 20 секунд нельзя удалить 15 секунд с начала и ещё 15 секунд с конца.

Уменьшите одно или оба значения.

## Stream copy не сработал

Это не обязательно ошибка приложения.

CutFlow Batch сначала использует `-c copy`. Некоторые исходные контейнеры, кодеки или дополнительные потоки нельзя без изменений записать в MP4. В этом случае программа автоматически пишет в лог сообщение о fallback и повторяет обработку с H.264/AAC.

Если fallback завершился успешно, итоговый статус будет **Готово**.

## После fallback пропали субтитры или дополнительные потоки

Fallback явно выбирает видео- и аудиопотоки и создаёт MP4. Это сделано для надёжности, поскольку некоторые типы субтитров и служебных потоков несовместимы с MP4.

Если необходимо сохранить все исходные потоки, предпочтителен успешный режим `-c copy` либо потребуется расширение логики приложения.

## Обработка завершается ошибкой

Посмотрите последние строки в **Логе обработки**.

Программа сокращает вывод FFmpeg до последних значимых строк, поэтому в большинстве случаев там будет причина: неподдерживаемый кодек, повреждённый файл, ошибка записи, отсутствие прав или другая проблема FFmpeg.

Дополнительно можно проверить исходник вручную:

```bat
ffprobe "D:\Video\input.mkv"
```

## Не удаётся создать папку вывода

Проверьте:

- существует ли диск;
- есть ли права записи;
- не указывает ли путь на защищённый системный каталог;
- нет ли недопустимых символов или проблем с сетевым ресурсом.

Для проверки выберите обычную папку пользователя, например:

```text
D:\CutFlowOutput
```

## Выходной файл уже существует

CutFlow Batch не перезаписывает предыдущий результат по имени.

Если существует:

```text
movie_cut.mp4
```

будет создан:

```text
movie_cut_1.mp4
```

а затем `_2`, `_3` и т. д.

## Отмена не происходит мгновенно

При нажатии **Отмена** приложение выставляет флаг отмены и вызывает завершение текущего процесса FFmpeg. Реальное завершение процесса может занять короткое время, после чего очередь останавливается.

Неполный выходной файл текущей операции удаляется.

## Приложение не запускается из исходников

Проверьте установку зависимостей:

```bat
python -m pip install -r requirements.txt
python main.py
```

Проверить PySide6:

```bat
python -c "import PySide6; print(PySide6.__version__)"
```

## EXE не запускается после сборки

Пересоберите приложение из чистого состояния:

```bat
rmdir /s /q build
rmdir /s /q dist
build_exe.bat
```

Если проблема остаётся, временно выполните запуск из исходников через `python main.py`. Это помогает отделить проблему приложения от проблемы упаковки PyInstaller.

## Настройки не сохраняются

Настройки записываются в `cutflow_settings.json` рядом с программой.

Если приложение находится в каталоге без прав записи, сохранение может не сработать. Переместите программу в пользовательскую папку с обычными правами записи.
