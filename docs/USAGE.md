# Использование CutFlow Batch

CutFlow Batch предназначен для пакетной обрезки одинакового количества секунд с начала и/или конца нескольких видеофайлов.

## 1. Добавление файлов

Нажмите **Добавить видео** и выберите один или несколько файлов.

Поддерживаемые расширения:

- `.mp4`
- `.mkv`
- `.mov`
- `.avi`
- `.webm`
- `.m4v`

Один и тот же файл нельзя добавить в очередь дважды. Неподдерживаемые расширения пропускаются и фиксируются в журнале.

## 2. Управление очередью

В таблице отображаются:

- полный путь к файлу;
- длительность;
- текущий статус.

Кнопка **Удалить выбранное** удаляет выделенные строки из очереди, а **Очистить список** удаляет все элементы.

Во время активной обработки изменение очереди и параметров блокируется.

## 3. Выбор папки вывода

Укажите папку в поле **Папка вывода** или нажмите **Выбрать папку вывода**.

Если поле пустое, приложение использует папку `output` рядом с `main.py` или `CutFlowBatch.exe`.

При необходимости папка создаётся автоматически.

## 4. Параметры обрезки

Доступны два независимых значения:

- **Обрезать начало, сек** — сколько секунд удалить с начала;
- **Обрезать конец, сек** — сколько секунд удалить с конца.

Допускаются дробные значения, например:

```text
0.5
1.25
15.000
```

Если сумма обрезки больше либо равна длительности видео, такой файл получает статус **Пропущен**.

## 5. Запуск

Нажмите **Старт**.

Для каждого файла CutFlow Batch:

1. получает длительность через FFprobe;
2. вычисляет итоговую длительность;
3. формирует уникальное имя выходного файла;
4. сначала запускает FFmpeg в режиме stream copy;
5. при ошибке удаляет неполный файл и повторяет обработку с H.264/AAC;
6. обновляет статус и общий прогресс.

## 6. Выходные имена

Исходные файлы не перезаписываются.

Для `episode01.mkv` выходное имя будет:

```text
episode01_cut.mp4
```

Если такой файл уже существует:

```text
episode01_cut_1.mp4
episode01_cut_2.mp4
...
```

## 7. Отмена обработки

Нажмите **Отмена**, чтобы остановить очередь.

Приложение отправляет запрос на завершение текущему процессу FFmpeg. Если для текущего элемента был создан незавершённый выходной файл, он удаляется.

Оставшиеся файлы после отмены не обрабатываются.

## 8. Статусы

В процессе работы могут отображаться статусы:

- **Ожидает**
- **Обработка**
- **Готово**
- **Пропущен**
- **Ошибка**
- **Отменён**

После завершения приложение показывает итоговое число успешных, ошибочных и пропущенных файлов.

## 9. Журнал обработки

Нижняя область интерфейса содержит лог с временными метками. В нём отображаются:

- добавление и удаление файлов;
- запуск очереди;
- переход на fallback-перекодирование;
- сохранение результата;
- ошибки FFprobe/FFmpeg;
- отмена обработки.

## 10. Сохранение настроек

CutFlow Batch сохраняет в `cutflow_settings.json`:

```json
{
  "output_directory": "D:/Video/output",
  "trim_start": 15.0,
  "trim_end": 15.0
}
```

Файл создаётся рядом с приложением и не добавляется в Git.

## Важное замечание о fallback

В быстром режиме `-c copy` FFmpeg пытается перенести все исходные потоки без перекодирования.

Если этот режим завершается ошибкой, fallback создаёт MP4 с:

- видео: H.264 (`libx264`), CRF 18, preset `veryfast`;
- аудио: AAC 192 kbit/s;
- `+faststart` для более удобного воспроизведения MP4.

Fallback выбирает видео- и аудиопотоки. Некоторые дополнительные потоки исходника, например несовместимые с MP4 субтитры, в такой выходной файл не попадут.
